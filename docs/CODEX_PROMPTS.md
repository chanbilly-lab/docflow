# docs/CODEX_PROMPTS.md

The project is designed so the user does not need to paste a long workflow prompt every time.

`AGENTS.md` contains the permanent instructions.

Use:

```text
执行 TASK-XXX。
```

To continue interrupted work:

```text
继续 TASK-XXX。
```

To re-check a completed task without intended feature changes:

```text
复核 TASK-XXX。
```

Examples:

```text
执行 TASK-001。
执行 TASK-010。
继续 TASK-017。
复核 TASK-021。
```
